基金分组聚类与相关性分析

一、总览（总）：各类型之间的关系

先看全局：每个节点是一个类型（大小 = 基金数，形状 = 类型，外圈 = 类型内部平均相关），连线上的数字 = 类型间平均相关系数，颜色越深、线越粗相关越强（红 = 正相关，绿 = 负相关）。鼠标悬停高亮某类型的连线；点击类型节点或表中的类型名，进入下方“分”视图查看该类型内部的聚类。

二、分组聚类网络图（分）

先按 funds_universe_example.csv 的“类型”列分组：用下拉框切换分组，观察组内哪些基金聚在一起、哪些基金相关度高。节点距离由相关系数决定（越近越相关），连线表示相关系数达到阈值；虚线色块为聚类范围。可拖动节点、点击基金查看其相关基金。“全部基金”是总视图（点击图例中的类型可进入该类型的分视图），其余为各类型的分视图；颜色越深相关越强。
